## 目的

長野市公式の各施設個別ページから、現状「要確認」になっている属性（サーフェス・面数・ナイター・料金・営業時間・電話番号）を埋めて、ベータ公開時に「使える検索サイト」状態にする。

スクレイピングではなく**公式ページの公開情報を手動転記**する形式なので法務リスクなし。

---

## 優先順位

CSV の `priority` 列を以下のように分類しています：

| 優先度 | 件数 | 着手タイミング | 該当施設 |
|---|---|---|---|
| **A** | 11 | Week 1 中に必ず完了 | 長野・南長野運動公園、御厨、城山、大豆島、緑ケ丘、昭和の森、古里、篠ノ井、川柳、北部スポレクパーク |
| **B** | 9 | Week 1〜2 で完了 | 若穂、豊野、西和田、茶臼山、青垣、真島、三輪、若穂多目的広場 など |
| **C** | 12 | Week 4 までに完了 | 河川敷（小松原・犀川各種・西寺尾・七二会）、鬼無里、飯綱高原 |

**判断基準:**
- A: 利用頻度が高い・主要施設（長野市中心部、面数の多い大規模公園）
- B: 一定の需要はあるがメイン施設の補完
- C: 河川敷の予約不要施設、遠方・標高高い施設（利用シーンが限定的）

## 1件あたりの作業フロー

### Step 1: 公式個別ページを開く

CSV の `official_subpage_url` 列のURLをブラウザで開く。

### Step 2: 以下を順に転記

| 列名 | 取得元の見方 | 例（御厨） |
|---|---|---|
| `court_count` | 「2面」「4面」などの記述 | `2` |
| `surface_type` | 「全天候型舗装」「砂入り人工芝」「クレー」など | `全天候型舗装` |
| `lighting_available` | 「ナイター設備あり/なし」「日没まで」表記 | `FALSE` |
| `operating_hours_summer` | 「5〜9月」「夏季」表記 | `6:30〜日没` |
| `operating_hours_winter` | 「10〜4月」「冬季」表記 | `8:30〜日没` |
| `closed_days` | 「年末年始」「月曜」など | `年末年始` |
| `parking` | 「駐車場あり(N台)」 | `あり` |
| `changing_shower` | 「更衣室・シャワー」 | （あれば`あり`/`なし`） |
| `fee_basic` | 「個人利用」「市民」料金 | `要PDF確認`(別途PDFあり) |
| `fee_lighting` | 「照明料金」「ナイター料金」 | （該当なし） |
| `fee_nonresident` | 「市民以外」料金 | `要PDF確認` |
| `phone_number` | 各施設の電話。なければ市スポーツ課代表 | `026-224-5083` |
| `notes` | 特記事項（PDFリンク等） | `料金PDF: /documents/3274/119446.pdf` |
| `status` | 作業状態 | `済` |
| `verified_at` | 確認日 | `2026-05-23` |

### Step 3: 緯度経度の取得（任意・後回し可）

CSV の `address` 列の住所を以下のいずれかで緯度経度に変換：

- 簡便法: Google Maps で住所検索 → URL の `@36.6601,138.1944,17z` 部分から取得
- 一括法: Phase 2 で `address` から Google Geocoding API でバッチ変換（住所が確定してから）

→ Week 1ではスキップしてOK。後でまとめてできます。

### Step 4: ファイル保存

CSV保存（Excel/Notion/Googleスプレッドシートのいずれでも可）。**CSVのまま管理する場合は文字コードUTF-8を維持**してください。

## よくある記述パターンと変換ルール

### サーフェス種別の標準化

| 公式記述 | DB列の値 |
|---|---|
| 砂入り人工芝 / オムニコート | `砂入り人工芝` |
| 人工芝 | `人工芝` |
| 天然芝 | `天然芝` |
| クレー / 土 | `クレー` |
| ハードコート / コンクリート / アスファルト / 全天候型舗装 | `ハード` |
| 体育館床 | `体育館床` |
| 記載なし / 不明 | `要確認` |

### ナイター（lighting_available）

| 公式記述 | DB値 |
|---|---|
| 「ナイター設備あり」「照明あり」「夜間利用可」 | `TRUE` |
| 「日没まで」「ナイター設備なし」 | `FALSE` |
| 記載なし | 空欄（NULL） |

### 営業時間

- 「夏季」「5月〜9月」などの記述があれば `operating_hours_summer` と `operating_hours_winter` を分ける
- 通年同じ場合は両列に同じ値を入れる

## 重要な気づき（既に判明）

### 北部スポーツ・レクリエーションパーク屋内運動場 (NAG-SOC-003)

- 屋内施設で**テニス4面・フットサル2面**を提供
- 現在DBでは「サッカー/フットサル」分類だが**テニスも提供**
- → 補完時に注記しておけば、私の方で `facility_sports` テーブルに `tennis` も追加します
- 個人利用2時間1,220円、ナイター料金810円/時間（全面）

### 河川敷施設（犀川第一・第二・南、西寺尾、小松原 など）

- ほとんどが「予約不要・受付なし・当日空き利用」
- 河川敷のためサーフェスは概ね**クレー/土**の可能性が高い（現地確認推奨）
- 詳細な営業時間規定がないことが多い → `closed_days` 等は空欄でOK

### 主要施設（長野・南長野運動公園）

- 大規模公園内の総合運動場
- テニス、サッカー、陸上等の複合施設
- 個別ページに詳細料金表（市民/市外、抽選/先着）が記載されている可能性大
- → 最優先で確認
