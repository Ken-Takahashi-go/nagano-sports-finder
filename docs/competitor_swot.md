# 競合分析 — テニスのコート様 SWOT

- **対象**: テニスのコート様（https://tennis.court-sama.com/）
- **比較対象**: 長野県公共施設ナビ（仮称）
- **作成日**: 2026-05-23

---

## テニスのコート様 — サービス概要

- 全国対応のテニスコート予約**自動代行**アプリ（iOS/Android）
- 利用者が予約サイトのID/PWをアプリに預ける → アプリが空きを監視 → 条件マッチしたら自動予約
- **料金: 無料**、ポイント制（月300pt付与 → 2024年9月から予約実績ユーザーのみに縮小）
- App Store 評価: 4.0、レビュー数: **8件**（極めて少ない＝ニッチサービス）
- **長野県対応: 公開情報上は確認できず**（対応自治体リストが公開されていない）

---

## SWOT 分析

### 対象 = テニスのコート様

#### Strengths（強み）
- **モバイルアプリで完成度高い**（iOS/Android両対応）
- **「予約代行」という強い機能**: ユーザーが指定条件を登録すれば自動で予約取得
- **全国対応をうたう**: 都市部の主要自治体は概ねカバー
- **テニス愛好家への深いフォーカス**: 機能が特化されている

#### Weaknesses（弱み）
- **ユーザーがID/PWを預ける構造のリスク**: セキュリティ・心理的ハードル高
- **コスト負担が運営の重し**: 2024-09に持続性懸念によるポイント縮小
- **ユーザー数が小さい**: レビュー数8件は地方/全国アプリとして極小
- **テニスのみ**（サッカー/フットサル/その他競技は対応外）
- **施設の静的属性比較は弱い**: サーフェス・ナイター・料金などの比較UIが薄い
- **「検索して比較する」用途には向かない**: あくまで予約自動化ツール
- **長野県対応は不明**: 地方都市での実利用は限定的の可能性

#### Opportunities（市場機会）
- **公共スポーツ施設の利便性向上は国レベルでも課題**（スポーツ庁「学校体育施設の有効活用」等）
- **自治体側もダッシュボード需要を認識し始めた**（ウイングアーク1st × スマートバリュー、2024-04）
- **稼働率データ蓄積プレイヤーの台頭余地**
- **地方都市の高齢化に伴う「探しにくい層」のフォロー需要**

#### Threats（脅威）
- **自治体協業型プレイヤーの拡大**（例: いばらき公共施設予約システム）
- **大手予約システムベンダーが提供側で機能追加する可能性**（リザエン、まちかぎリモート等）
- **スクレイピング規制強化**（利用規約改定、技術的ブロック導入）

## 長野県公共施設ナビ vs テニスのコート様 — ポジショニング

| 観点 | テニスのコート様 | 長野県公共施設ナビ |
|---|---|---|
| **主機能** | 予約自動代行 | 横断検索・比較 |
| **対応競技** | テニスのみ | テニス + サッカー + フットサル |
| **対象地域** | 全国（実態は都市部中心） | 長野県特化 |
| **ID/PW預け** | 必要 | 不要（リスク低） |
| **施設属性比較** | 弱い | 強み（サーフェス・ナイター・料金等） |
| **モバイル対応** | アプリ（iOS/Android） | レスポンシブWeb |
| **公開チャネル** | アプリストア | SEO主体 |
| **データ蓄積** | 不明 | Day 1から時系列蓄積（差別化資産） |
| **収益モデル** | 不明（ポイント制） | ハイブリッド（広告＋自治体SaaS） |

## 戦略的示唆

### 1. 差別化の明確な方向性

長野県公共施設ナビは **「予約代行」ではなく「探しやすさ・比較」** に振り切る。
- ID/PW預けが不要な分、初回ハードルが圧倒的に低い
- テニス利用者に加え、競合空白の **サッカー幹事層** を取れる
- 静的属性（サーフェス、ナイター、料金、駐車場）比較で価値訴求

### 2. 「コート様」が苦戦している領域に入る

- **長野県特化** → 全国アプリでは情報粒度が荒い
- **検索ファースト** → 「予約まで決めていない／比較したい」ユーザー層
- **SEO流入** → 「長野市 テニスコート 空き」「松本 人工芝 サッカー場」等

### 3. データ蓄積で自治体SaaSの先行者利益を取る

- テニスのコート様は予約代行に特化していて稼働率データは持っていない
- ウイングアーク1st × スマートバリューは予約システムベンダー側からの参入
- **「中立的なデータアグリゲーター」というポジションは空白**

### 4. リスクシナリオ

- 自治体側がテニスのコート様への取り締まりを始めたら、こちらも巻き込まれる可能性
- → **正攻法での協業ルートを Phase 2 から並行で進める**（防御策）

---

## 結論

テニスのコート様は名目上の競合だが、**長野県という地理 × 検索/比較という機能** の組み合わせでは実質競合は不在。
むしろ「予約代行＝重い／怖い」と感じるユーザーの受け皿になれる。

差別化の3本柱：
1. **横断検索 × 比較** （予約代行ではなく）
2. **長野県特化 + サッカー/フットサル領域**
3. **時系列データ蓄積 → 自治体SaaSへの長期展開**
