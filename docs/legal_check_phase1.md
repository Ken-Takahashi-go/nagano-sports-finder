**全体所感:**
- 4システムとも公開ページレベルでは**スクレイピング禁止を明示する文言が見当たらない**

## システム別詳細

### 1. 長野市 まちかぎリモート

- **URL**: https://city.nagano.nagano.machikagi-remote.jp/
- **運営**: 株式会社ライナフ（不動産系スマートロックベンダー）
- **特徴**: 2024年6月に刷新の新システム。スマートロック連携、オンライン決済対応
- **空き状況閲覧**: ログイン不要で可能
- **規約に関する観察**:
  - トップページに「スクレイピング」「ロボット」「再配布」「商用利用」の文言なし
  - robots.txt は標準コメントのみで、明示的な `Disallow` 指定なし
  - 利用規約PDFや別ページの存在は要追加調査
- **PoC候補（推奨）**: 施設一覧ページ → 個別施設 → 空き状況カレンダー の3画面構造になっている可能性。SPA かもしれず Playwright 必須の可能性あり

**判定: △ 慎重に可**
- 初期は手動取得で1施設のみ試験
- 自動化前にライナフ社のサービス利用規約も確認

## スクレイピング実施時の必須遵守事項

技術的・法的リスクを抑えるため、以下を必ず守る。

### 技術的ガードレール

1. **アクセス間隔**: 同一ホストへ最短 **15秒に1リクエスト**（自治体システムなので余裕を持つ）
2. **時間帯**: 深夜帯（02:00-04:00 JST）に集中させ、市民の利用時間帯を避ける
3. **User-Agent明示**:
   ```
   NaganoSportsFinder/0.1 (+https://your-site.example/about; contact@example)
   ```
4. **エラー時**: 3回連続失敗で当該システムへの取得を24時間停止
5. **取得対象限定**: 空き状況のみ。個人情報・予約者氏名等は絶対に取得しない
6. **キャッシュ**: 同一URLは15分以内に再取得しない
7. **HTTPSのみ・robots.txt 都度確認**

### 法的ガードレール

1. **出典明示**: 全施設詳細ページに「データ提供元: ○○市公共施設予約システム」と表示
2. **公式リンク優先表示**: 予約は必ず公式サイトに送る（自前で予約処理しない）
3. **「最終確認時刻」明示**: ユーザーに鮮度が低い可能性を伝える
4. **再配布禁止**: APIエクスポート機能やCSVダウンロード機能は Phase 1 では作らない
5. **問い合わせ窓口設置**: フッターに連絡先メールアドレスを表示。24時間以内に取得停止対応
6. **規約ページの保存**: 各システムの利用規約・FAQをPDF保存し、 `docs/legal/` に日付付きで保管

### 自治体からの問い合わせ対応プロトコル

1. **第一報受領 → 24時間以内に該当自治体分の取得を一時停止**
2. **企画書を持って対面説明**: 「住民の利便性向上のため。データ利用方法はこうです」
3. **代替案提示**: 公式CSV/API提供の協議に切替（[いばらき公共施設予約システム](https://www.pref.ibaraki.jp/kikaku/joho/chiiki/yoyaku/yoyakutsukao.html)モデル）
4. **撤退基準**: 自治体が明確に拒否した場合は当該自治体を一旦外す（Phase 1.5 まで凍結）

## 結論

Phase 1（長野市1市集中）の範囲では、**現時点で明示的禁止が確認されていないため技術的に着手は可能**。

ただし以下を遵守すること：
1. 技術的・法的ガードレールを最初から組み込む
2. 「PoCで取れるか」のテスト前に、長野市まちかぎリモートの利用規約PDFを再度確認
3. 公開ベータ開始時に弁護士に最終レビューを受ける
